

# 01. Context Engineering


## 1. Evolution of the Paradigm (The Buzzwords)
*   2023: Prompt Engineering (Crafting the exact wording of a single query)
*   2024: Vibe Coding (Building software primarily through natural language iteration)
*   2025: Context Engineering (Curating the entire informational ecosystem fed into the LLM)
*   2026: Agentic Engineering (Autonomous systems acting, reasoning, and executing tasks)


 


## 2. Prompt vs. Context: What’s the Difference?
*   Prompt: The specific instruction or query provided directly by the user at the moment.
*   Context: The comprehensive package of information assembled from various sources (along with the user input) and passed to the LLM to give it the necessary background and capabilities to respond effectively.


 


## 3. The 6 Stages of Building a Context
When building a robust context, you combine the user query with these six core elements:
1.  System Instruction: Core guidelines, persona, rules, and boundaries.
2.  Conversation History: Past turns of dialogue for continuity.
3.  Retrieved Knowledge: External data fetched via RAG (Retrieval-Augmented Generation), databases, or docs.
4.  Tools & Definitions: Available APIs, functions, and schemas the model can call.
5.  State & Memory: Current application state, variables, and long-term user preferences.
6.  User Input: The immediate query or command.


 


## 4. Frameworks in Context Engineering
1.  Six Elements of Context (Listed above)
2.  LLM as OS (Treating the LLM like an operating system managing memory, tools, and processes)
3.  WSCI (Write, Select, Compress, Isolate)
4.  Right Altitude (Finding the correct level of abstraction/detail in the context)
5.  PRP Workflow
6.  ReAct (Reason + Act framework for agents)
7.  Three-Tier Memory (Short-term, working, and long-term memory systems)
8.  Token Budgeting (Managing constraints and costs within the token limit)


 


## 5. Context Window Sizes & Management
Different models offer vastly different capacities for holding information:
*   GPT-4o: ~128k tokens
*   Claude Opus: ~1M tokens
*   GPT-5 (Hypothetical/Future): ~400k+ tokens


### Context Management Commands (e.g., Claude Code)
*   /clear: Completely wipes out the built-up context.
*   /compact: Summarizes and compresses the existing context to free up token space for new interactions.


 


## 6. Fascinating Phenomena in Context Engineering


*    Lost in the Middle: Research shows that LLMs pay high attention to information at the very beginning and very end of a context window, but tend to gloss over or ignore details buried in the middle. 
*    Repeat Prompt Experiment: Studies indicate that repeating the core user query twice (e.g., query... query...) inside the context can sometimes yield significantly better outputs. (The exact cognitive mechanism behind this is still an active area of study).
